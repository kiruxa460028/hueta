# DOTA PROTRACKER — клон меты Dota 2

Веб-приложение в стиле [dotaprotracker.com](https://dotaprotracker.com): статистика профессиональных
и рейтинговых матчей Dota 2, мета героев, тир-листы, профили игроков и команд, детальные
страницы матчей с драфтами и графиками.

**Демо-проект:** все матчи и статистика детерминированно сгенерированы на клиенте
(seeded PRNG) и внутренне согласованы — винрейты, матчапы, предметы и рейтинги считаются
из одного и того же набора матчей. Ростеры команд приблизительные. Изображения героев
и предметов подгружаются с официального Steam CDN.

## Возможности

**Живые данные (основной режим).** При загрузке сайт обращается к публичному
[OpenDota API](https://docs.opendota.com) прямо из браузера (CORS, без ключа) и показывает:
- реальные винрейты/пики/баны всех героев по брекетам: **Про / Immortal / Divine**
  (heroStats: pro_*, 8_*, 7_*) + тренды за последние дни;
- ленту **реальных про-матчей** (турниры, команды, счёт, длительность — proMatches);
- страницы реальных матчей: **настоящие драфты (пики/баны), скорборды с предметами,
  графики преимущества по золоту и опыту** (radiant_gold_adv / radiant_xp_adv);
- **реальные команды** с Elo-рейтингом, логотипами, составами и историей матчей;
- **реальные профили игроков** (ранг, MMR, W/L, последние матчи, герои);
- на страницах героёв — **реальные матчапы** («силён против» / «слаб против»),
  **топ игроков на герое** (rankings) и **статистику предметов** (itemTimings);
- кэш в localStorage (мета 30 мин, матчи 2 мин, детали матчей 24 ч).

**Демо-режим (автооткат).** Если OpenDota недоступна (нет интернета, API лежит),
сайт бесшовно переключается на встроенный офлайн-генератор: детерминированные матчи,
мета, игроки и команды. Источник данных всегда виден по индикатору в шапке
(зелёный «OpenDota» / жёлтый «Демо-данные») и плашкам на страницах.

Остальное:
- Переключатель брекетов (Про / Immortal / Divine) влияет на всю статистику
- Тир-лист S/A/B/C/D по винрейту и популярности, сортировка и фильтры таблицы героев
- Графики (SVG): динамика винрейта, преимущество по золоту/опыту с тултипами
- Глобальный поиск (герои / команды / игроки) с хоткеем `/`
- Тёмная тема в стиле dotaprotracker, адаптивная вёрстка, русская локализация

## Стек

- **React 18 + React Router 6** — SPA
- **Vite 5** — сборка и dev-сервер
- Чистый CSS (дизайн-система в `src/styles.css`)
- SVG-графики без внешних библиотек
- Данные: 127 героев (реальные данные OpenDota API: атрибуты, роли), ~80 предметов,
  44 команды и 220 про-игроков + пул паб-игроков; ~5600 сгенерированных матчей за 30 дней

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # продакшен-сборка в dist/
```

Смоук-тест рендера всех маршрутов (SSR, офлайн-режим):

```bash
node scripts/ssr-test.mjs
```

Тест живого слоя данных (адаптеры OpenDota на моках):

```bash
node scripts/live-test.mjs
```

## Структура

```
src/
  data/
    heroes.js     # 127 героев: атрибуты, роли, имена для Steam CDN
    items.js      # каталог предметов + пулы по позициям
    scene.js      # команды, ростеры, турниры, генератор паб-ников
    db.js         # seeded-генератор матчей + все селекторы (мета, матчапы, рейтинги)
  components/     # Header, таблицы, графики, иконки, строки матчей
  pages/          # Home, Heroes, HeroDetail, Players, PlayerDetail,
                  # Teams, TeamDetail, Matches, MatchDetail, Search
  context.jsx     # контекст выбранного брекета (Про/Immortal/Divine)
  styles.css      # тёмная дизайн-система
```
