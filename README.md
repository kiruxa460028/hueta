# DOTA PROTRACKER — клон меты Dota 2

Веб-приложение в стиле [dotaprotracker.com](https://dotaprotracker.com): статистика профессиональных
и рейтинговых матчей Dota 2, мета героев, тир-листы, профили игроков и команд, детальные
страницы матчей с драфтами и графиками.

**Демо-проект:** все матчи и статистика детерминированно сгенерированы на клиенте
(seeded PRNG) и внутренне согласованы — винрейты, матчапы, предметы и рейтинги считаются
из одного и того же набора матчей. Ростеры команд приблизительные. Изображения героев
и предметов подгружаются с официального Steam CDN.

## Возможности

- **Живые матчи** — карточки с тикающим таймером, текущим счётом и преимуществом по золоту
- **Лента матчей** — про-матчи (турниры, стадии, серии Bo2/Bo3/Bo5) и пабы Immortal/Divine
- **Переключатель брекетов** — Про / Immortal / Divine (влияет на всю статистику)
- **Мета героев** — таблица с пиками, банами, пикрейтом, банрейтом, винрейтом, KDA,
  GPM, трендами и спарклайнами; сортировка по любой колонке; фильтры по атрибуту и ролям
- **Тир-лист** S/A/B/C/D, рассчитанный по винрейту и популярности
- **Страница героя** — ключевые статы, график винрейта по дням, лучшая синергия,
  худшие матчапы (контрпики), топ игроков на герое, популярные предметы, последние матчи
- **Игроки** — рейтинг по брекетам, MMR для пабов, профиль со статами, героями и матчами
- **Команды** — рейтинг, состав, топ героев, история матчей
- **Страница матча** — пики и баны (драфт), графики преимущества по золоту и опыту
  с тултипами, полные скорборды обеих команд (KDA, GPM/XPM, нетворт, урон, предметы)
- **Глобальный поиск** — живые подсказки по героям/игрокам/командам, хоткей `/`
- Тёмная тема, адаптивная вёрстка, русская локализация интерфейса

## Стек

- **React 18 + React Router 6** — SPA
- **Vite 5** — сборка и dev-сервер
- Чистый CSS (дизайн-система в `src/styles.css`)
- SVG-графики без внешних библиотек
- Данные: 127 героев (реальные данные OpenDota API: атрибуты, роли), ~80 предметов,
  44 команды и 220 про-игроков + пул паб-игроков; ~5600 сгенерированных матчей за 30 дней

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # продакшен-сборка в dist/
```

Смоук-тест рендера всех маршрутов (SSR):

```bash
node scripts/ssr-test.mjs
```

## Структура

```
src/
  data/
    heroes.js     # 127 героев: атрибуты, роли, имена для Steam CDN
    items.js      # каталог предметов + пулы по позициям
    scene.js      # команды, ростеры, турниры, генератор паб-ников
    db.js         # seeded-генератор матчей + все селекторы (мета, матчапы, рейтинги)
  components/     # Header, таблицы, графики, иконки, строки матчей
  pages/          # Home, Heroes, HeroDetail, Players, PlayerDetail,
                  # Teams, TeamDetail, Matches, MatchDetail, Search
  context.jsx     # контекст выбранного брекета (Про/Immortal/Divine)
  styles.css      # тёмная дизайн-система
```
